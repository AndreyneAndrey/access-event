# Анализ стейкхолдеров проекта AccessEvent

В данном документе представлен подробный анализ заинтересованных сторон (стейкхолдеров) инклюзивной платформы мероприятий, их ключевые интересы, требования к веб-платформе и уровень влияния на успешную реализацию ИТ-проекта.

| Стейкхолдер (Роль) | Основные интересы в проекте | Ключевые требования к системе | Влияние |
| :--- | :--- | :--- | :--- |
| **Организаторы мероприятий** | Быстрое создание инклюзивных событий, привлечение аудитории с нарушениями слуха, сбор обратной связи. | Удобная панель управления, инструменты аналитики, кастомизация страниц встреч. | Высокое |
| **Участники (с нарушениями слуха)** | Беспрепятственный доступ к информации, своевременные оповещения, отсутствие звуковых барьеров. | Соответствие стандартам WCAG 2.1 AA, контрастный интерфейс, текстовые чаты и визуальные баннеры. | Высокое |
| **Администраторы платформы** | Модерация контента, обеспечение безопасности данных, контроль стабильности и работоспособности. | Разграничение прав доступа, удобные инструменты блокировки нарушителей, просмотр логов действий. | Среднее |
| **Владелец платформы (Бизнес)** | Рост пользовательской базы, оценка востребованности сервиса, масштабирование ИТ-решения. | Подробная статистика посещаемости, надежный стек (Flask + PostgreSQL), низкая стоимость поддержки. | Высокое |
